# Seven 的彩虹成长岛

一个为 3 岁半幼儿设计的每日趣味学习打卡网站，覆盖英语、语文、数学、科学、创意规律和运动习惯。

## 运行

这是一个零依赖网站，直接双击 `index.html` 可以在当前电脑使用。

### 让手机和 iPad 访问

1. 双击 `start.command`。
2. macOS 第一次询问网络权限时选择允许。
3. 终端会显示一个类似 `http://192.168.1.20:8000/` 的地址。
4. 让手机、iPad 和电脑连接同一个 Wi-Fi，在 Safari 中打开该地址。
5. 可以点击 Safari 的“分享”→“添加到主屏幕”。

也可以在当前目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 功能

- 6 个可互动的每日学习任务
- 4 集原创 Canvas 动画小视频，覆盖英语、汉字、数学和科学
- 5 集无广告开放授权实拍/科学动画：种子、月亮、云、蜂鸟蛾和甲虫
- 视频支持播放、暂停、拖动、重播、字幕与语音讲解
- 看完视频可获得“小放映员”徽章，并提供亲子讨论问题
- 家长可添加已经审核过的 B 站 BV 视频，使用官方播放器、关闭弹幕且不自动播放
- 家庭 Wi-Fi 局域网访问、网址复制/分享与主屏幕安装支持
- 完成任意 4 个任务即可打卡
- 星星、连续打卡与本周成长记录
- 英语发音、鼓励音效和庆祝动画
- 家长小屋：查看进度、修改称呼、重置今日记录
- 所有数据只保存在当前浏览器的 `localStorage` 中
- 支持手机、平板和桌面屏幕

## 关于 B 站视频

网站不会自动搜索或推荐 B 站内容。家长需要先完整观看并确认视频适龄、没有商业植入，再在“家长小屋”粘贴视频链接或 BV 号。播放器界面和平台推荐由 B 站控制，网站无法永久保证第三方平台不会改变展示内容，因此建议始终由家长陪同观看。

预置的 5 集真实世界视频不经过 B 站或其他广告播放器，直接读取 Wikimedia Commons 视频文件，并在播放器下方标注作者和开放许可。

## 公网部署

项目已包含 GitHub Pages 自动部署工作流：`.github/workflows/deploy-pages.yml`。推送到公开 GitHub 仓库并将 Pages 来源设为 GitHub Actions 后，每次更新 `main` 分支都会自动发布 HTTPS 网站。

已经登录 GitHub CLI 的 Mac 可以直接双击 `deploy-github.command`。脚本会创建公开的 `seven-rainbow-island` 仓库、推送代码、启用 GitHub Pages，并在终端中显示公网网址。

## 数据说明

不同手机和 iPad 的打卡记录分别保存在各自浏览器中，目前不会跨设备同步。
