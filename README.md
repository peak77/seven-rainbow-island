# Seven 的彩虹成长岛

一个为 3 岁半幼儿设计的每日趣味学习打卡网站，覆盖英语、语文、数学、科学、音乐、运动和生活综合。

## 运行

这是一个零依赖网站，直接双击 `index.html` 可以在当前电脑使用。

### 让手机和 iPad 访问

1. 双击 `start.command`。
2. macOS 第一次询问网络权限时选择允许。
3. 终端会显示一个类似 `http://192.168.1.20:8000/` 的地址。
4. 让手机、iPad 和电脑连接同一个 Wi-Fi，在 Safari 中打开该地址。
5. 可以点击 Safari 的“分享”→“添加到主屏幕”。

也可以在当前目录运行：

```bash
python3 server.py --port 8000
```

然后访问 `http://localhost:8000`。项目自带的服务器支持视频 Range 请求，拖动进度和弱网续播会更稳定。

## 功能

- 每天稳定轮换的 7 科互动任务；每科 5 个内容变体，共 35 个
- 3 个原创兴趣英雄奖励关：宇宙能量规律、安全警犬判断、迷你行动队英语口令
- 儿童安全模式默认隐藏分享、第三方视频和管理设置；家长验证后才会开放
- 首页优先展示今日任务，并提供手机底部“今日 / 视频 / 星星”快捷入口
- 手机和 iPad 快捷导航会根据当前浏览位置自动高亮
- 7 集 720P 原创 Canvas 动画，覆盖英语、语文、数学、科学、音乐、运动和综合
- 5 集本站托管的 720P / 1080P 高清开放授权视频：种子、月亮、云、蜂鸟蛾和甲虫；优先使用 iPhone / iPad 兼容的 H.264 MP4，并保留 WebM 备用源
- 7 集原创动画和 5 集高清实拍均支持中文、英语、中英双语、日语、西班牙语、法语和德语讲解
- 高清视频不依赖境外播放器，只要网站能打开就能直接播放，无需 VPN
- 视频支持播放、暂停、拖动、重播、字幕与语音讲解
- 看完视频还要完成一个适龄小动作，之后才能获得视频徽章
- 家长模式可添加已经审核过的 B 站 BV 视频；儿童模式不会显示第三方视频
- 视频库不设固定数量上限，支持中文、英语、中英双语及其他语言标签
- 视频较多时可按关键词、语言和学科筛选，并每次显示 6 个，筛选项会显示真实数量
- 每一个学科筛选项都至少有一集可直接播放的视频
- 家庭 Wi-Fi 局域网访问、网址复制/分享与主屏幕安装支持
- 完成任意 4 个任务即可打卡
- 星星、连续打卡与本周成长记录
- 所有任务均可自动朗读和“再听一遍”；连续答错时会温柔读出提示
- 自动优选设备上接近真人的温柔女性声音，并为中文、英语、日语、西班牙语、法语和德语分别调整语速
- 支持温柔女声、活力小队长、清晰小老师三种讲解风格
- 英语发音、自然中文讲解、鼓励音效和庆祝动画
- 家长小屋：查看进度、试听/选择设备语音、修改称呼、管理视频、备份或导入成长记录
- 所有数据只保存在当前浏览器的 `localStorage` 中
- 页面跨午夜或从后台恢复时会自动换成新一天的任务
- 成长记录导入会先校验和清洗数据，失败时不会覆盖当前记录
- 支持手机、平板和桌面屏幕

## 关于 B 站视频

网站不会自动搜索或推荐 B 站内容。家长需要先完整观看并确认视频适龄、没有商业植入，再在“家长小屋”粘贴视频链接或 BV 号。播放器界面和平台推荐由 B 站控制，网站无法永久保证第三方平台不会改变展示内容，因此建议始终由家长陪同观看。

预置的 5 集真实世界视频不经过 B 站或其他广告播放器。开放授权的高清视频文件保存在 `assets/videos/` 中并随网站一起发布，播放器下方继续标注作者、来源和许可。

## 公网部署

网站使用 `main` 分支根目录直接发布到 GitHub Pages，不需要创建 GitHub Actions 工作流，也不需要 OAuth 的 `workflow` 权限。

已经登录 GitHub CLI 的 Mac 可以直接双击 `deploy-github.command`。脚本会创建公开的 `seven-rainbow-island` 仓库、推送代码、启用 GitHub Pages，并在终端中显示公网网址。

## 数据说明

不同手机和 iPad 的记录默认分别保存在各自浏览器中。可以在家长小屋导出 JSON 成长记录，再在另一台设备导入；网站不会自动上传孩子的数据。
