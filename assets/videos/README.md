# 本站高清开放视频

这些视频文件与 Seven 的学习网站一起托管，播放时不需要访问第三方视频平台。

| 本地视频（MP4 优先 / WebM 备用） | 清晰度 | 来源与许可 |
| --- | --- | --- |
| `lettuce-sprout-720p.mp4` / `.webm` | 1280×720 | Dwight Sipler，Wikimedia Commons，CC BY 2.0 |
| `moon-sides-1080p.mp4` / `.webm` | 1920×1080 | NASA Scientific Visualization Studio，Public Domain |
| `cloud-water-1080p.mp4` / `.webm` | 1920×1080 | NASA Scientific Visualization Studio，Public Domain |
| `moth-flower-1080p.mp4` / `.webm` | 608×1080 竖屏 | Natalka Ukraine，Wikimedia Commons，CC BY 4.0 |
| `beetle-leaf-1080p.mp4` / `.webm` | 608×1080 竖屏 | Natalka Ukraine，Wikimedia Commons，CC BY 4.0 |

MP4 使用 H.264 High@4.1、`yuv420p` 和网页快速启动布局；带原声的两段视频转为 AAC-LC。播放器优先尝试 MP4，再回退到原始 WebM。

原始作品页面和作者信息仍保留在 `app.js` 的 `OPEN_VIDEOS` 数据中，播放器会显示对应的来源与许可链接。
